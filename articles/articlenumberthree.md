## What is Information Technology?

**Information Technology (IT)** is the use of computers, software, networks, and digital systems to create, process, store, retrieve, and communicate information.

An IT professional helps technology remain reliable, secure, and efficient. That work can include installing software, maintaining devices, managing user accounts, troubleshooting networks, protecting information, and helping users solve problems.

## The five major areas of IT

### 1. Computer hardware

Hardware is the physical equipment that makes up a computer or network. Common examples include CPUs, RAM, motherboards, storage drives, keyboards, monitors, printers, and GPUs.

### 2. Software and operating systems

Software consists of programs and instructions that tell hardware what to do. Operating systems such as Windows 11, macOS, and Linux manage the computer and provide an environment for applications.

### 3. Networking

Networking connects computers and devices so they can communicate and share resources. It includes technologies such as Wi-Fi, Ethernet, routers, switches, and the internet.

### 4. Cybersecurity

Cybersecurity protects systems, networks, and information from unauthorized access, attacks, and damage. Important concepts include firewalls, strong passwords, encryption, antivirus tools, and access controls.

### 5. Technical support

Technical support helps people install and configure technology, fix problems, and keep devices operational. Troubleshooting is a systematic process: identify the issue, isolate its source, test a solution, and verify the result.

These areas overlap frequently. A support technician might discover that a hardware problem is actually caused by a software setting or that a system failure involves both networking and access-control issues.

## How a computer processes information

Every computer follows four basic functions:

| Function | Description | Example |
\
| --- | --- | --- |
\
| Input | Information enters the computer | Pressing keys on a keyboard |
\
| Processing | The computer works with the information | A word processor handling each keystroke |
\
| Output | Results are presented to the user | Words appearing on a monitor |
\
| Storage | Information is saved for later use | Saving a document to an SSD |

Typing and saving a document in Microsoft Word demonstrates all four functions: the keyboard provides input, the application processes it, the monitor displays it, and the SSD stores it.

## Hardware vs. software

**Hardware** is the physical equipment you can touch. Important components include:

| Component | Purpose |
\
| --- | --- |
\
| CPU | Processes instructions |
\
| RAM | Temporarily holds active data |
\
| Motherboard | Connects computer components |
\
| SSD | Provides fast long-term storage |
\
| HDD | Provides magnetic long-term storage |
\
| GPU | Processes graphics |
\
| PSU | Supplies electrical power |
\
| Monitor | Displays visual output |

**Software** is the set of programs and instructions that tell hardware what to do. Applications such as Chrome, Microsoft Word, Steam, and Discord run within an operating system. Hardware can be present and healthy, but it is not useful in the way users expect without software.

## The role of an operating system

An **operating system (OS)** manages hardware and software resources and provides the interface used to operate a computer.

Its key responsibilities are:

- Coordinating hardware such as the CPU, memory, storage, and devices
- Organizing files and folders
- Managing running programs and system resources
- Providing a graphical or command-line user interface
- Managing user accounts, permissions, and system security

Windows is one of several major operating systems encountered in IT. macOS is Apple's operating system, Linux is an open-source operating system family used widely in servers and infrastructure, and Android is a mobile operating system.

## My first Windows 11 lab

This lesson also gave me an introductory hands-on task using Windows 11.

### 1. Review system specifications

Right-click the Windows Start button, select **System**, and inspect:

- Device specifications, including processor and installed RAM
- Windows specifications, including the operating system and version

### 2. Open Task Manager

Press `Ctrl + Shift + Esc`, open **Performance**, and review:

- CPU activity
- Memory and RAM usage
- Storage disk activity
- GPU usage, if available

Task Manager is useful during troubleshooting. When a computer is slow, CPU, memory, and disk utilization can provide important clues about resource usage and the source of the problem.
